# 30. Les mutants équivalents : le faux positif du mutation testing

**Statut :** idée, non rédigée. **Effort :** moyen.

**Thèse.** Tous les mutants ne se valent pas : certains ne changent pas le comportement et ne peuvent pas être tués.

## Plan

1. Un exemple concret, écrit et vérifié avec Infection.
2. Pourquoi c'est difficile en général de les détecter automatiquement.
3. Comment les reconnaître à la main.
4. Les exclure sans masquer de vrais trous de couverture.
5. L'effet sur le score (MSI) et comment le lire.

## Matière

- **À produire :** l'exemple, sur du code réel.
- **À recouper :** la notion de mutant équivalent dans la littérature du mutation testing, avant de l'affirmer.
