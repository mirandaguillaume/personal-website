# 34. Lire un EXPLAIN : ce que mes pires requêtes m'ont appris

**Statut :** idée, non rédigée. **Effort :** moyen.

**Thèse.** Une requête lente se diagnostique en lisant son plan, pas en devinant.

## Plan

1. La requête lente (à vous).
2. Lire un `EXPLAIN` : type d'accès, nombre de lignes estimées, index utilisé.
3. Le correctif : index, réécriture.
4. Mesurer avant et après.
5. Le coût des index à l'écriture.

## Matière

- **À vous :** les requêtes, les chiffres et le SGBD.
- **À recouper :** la documentation du SGBD utilisé. Ne rien affirmer avant de savoir lequel.
