# 65. Le mot « workflow » veut dire trois choses

**Statut :** idée, non rédigée. **Effort :** faible. **Thème :** LLM.

**Thèse.** Le même mot désigne trois choses différentes selon qui parle. Les confondre fait mal comparer les outils.

## Plan

1. Anthropic : un workflow est un système où LLM et outils sont orchestrés par des chemins de code prédéfinis, par opposition à un agent qui dirige lui-même son processus (vérifié).
2. LangGraph : la même distinction, presque mot pour mot : chemins de code prédéterminés dans un certain ordre, contre un agent dynamique (vérifié).
3. Temporal : un workflow est du code durable, rejouable après un crash, qui doit être déterministe. Les appels non déterministes, dont les « LLM/AI invocations », vont dans des Activities (vérifié).
4. Les éditeurs graphiques (Rivet, Vellum, cités par Anthropic) : encore une autre manière de dessiner un workflow (à recouper avant de les décrire).
5. Pourquoi ça compte : choisir un outil, c'est choisir une définition.

## Matière

- **Vérifiée :** les trois premiers points, à partir de leurs pages de documentation.
- **À recouper :** tout ce qui concerne les éditeurs graphiques.
