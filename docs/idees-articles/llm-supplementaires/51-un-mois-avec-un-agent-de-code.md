# 51. Un mois avec un agent de code : bilan honnête

**Statut :** idée, non rédigée. **Effort :** faible. **Thème :** LLM.

**Thèse.** Un bilan chiffré et nuancé vaut mieux qu'un enthousiasme ou un rejet de principe.

## Plan

1. Le contexte : quelles tâches, quels projets, quel outil.
2. Ce qui a vraiment gagné du temps (à mesurer, pas à ressentir).
3. Ce qui en a fait perdre : relectures, corrections, détours.
4. Ce que vous avez changé dans votre façon de travailler.
5. Ce que vous recommandez, à qui, et sous quelles conditions.

## Matière

- **À vous :** tout. Pour que l'article ait de la valeur, il faut des mesures prises pendant le mois, pas reconstituées après.
