# 52. Mon client m'autorise-t-il à envoyer son code à un LLM ?

**Statut :** idée, non rédigée. **Effort :** moyen. **Thème :** LLM, freelance.

**Thèse.** Un freelance qui utilise un agent de code envoie du code et des données de son client à un tiers. La question mérite d'être posée avant, pas après.

## Plan

1. Ce qui part réellement : fichiers lus, sorties de commandes, variables d'environnement visibles.
2. Ce que dit (ou ne dit pas) votre contrat et celui du client.
3. Ce que disent les fournisseurs de l'usage des données selon l'offre (grand public, entreprise, API).
4. Les garde-fous pratiques : exclure des fichiers, ne pas lire les secrets, environnement séparé.
5. Comment en parler à un client.

## Attention

Ce n'est pas un avis juridique. Rester général et ne rien dire de précis sur vos clients.

## Matière

- **À vous :** votre pratique et vos contrats.
- **À recouper :** les conditions d'usage des données de chaque fournisseur, à lire dans les documents officiels au moment d'écrire.
