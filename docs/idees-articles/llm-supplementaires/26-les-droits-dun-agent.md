# 26. Les droits d'un agent : le moindre privilège

**Statut :** idée, non rédigée. **Effort :** moyen.

**Thèse.** Un agent ne devrait avoir que les droits nécessaires à sa tâche, comme tout autre processus.

## Plan

1. Ce qu'un agent peut faire aujourd'hui avec vos accès : shell, git, réseau, fichiers.
2. Le moindre privilège appliqué : permissions par outil, listes d'autorisation, environnements jetables.
3. L'injection de prompt : une page web ou un fichier peut contenir des ordres.
4. Les actions irréversibles ou visibles de l'extérieur demandent une confirmation.
5. Ce que vous avez réellement configuré (à vous).

## Matière

- **À vous :** votre configuration réelle, à n'exposer que si vous le décidez.
- **À recouper :** l'OWASP Top 10 for LLM Applications et la documentation des permissions de l'outil utilisé, avant toute affirmation de sécurité.
