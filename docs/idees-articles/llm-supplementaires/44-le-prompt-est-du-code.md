# 44. Le prompt est du code

**Statut :** idée, non rédigée. **Effort :** moyen. **Thème :** LLM.

**Thèse.** Un prompt qui pilote un workflow se versionne, se relit en PR et se teste comme n'importe quel autre code.

## Plan

1. Le prompt perdu dans une interface web ou un coin de Notion.
2. Le mettre dans le dépôt : fichier, revue, historique, blame.
3. Le paramétrer sans le bricoler : gabarits, variables, tests de rendu.
4. Le tester : cas d'essai, propriétés de sortie (voir 20).
5. Ce que ça change : un changement de prompt devient un changement de comportement, avec un diff.

## Matière

- **À vous :** votre propre organisation, avec un exemple avant/après.
