# 25. Ce qui se calcule ne se demande pas à un LLM

**Statut :** idée, non rédigée. **Effort :** faible.

**Thèse.** Dès qu'une réponse est calculable, calculez-la : le LLM décide quoi calculer, le code calcule.

## Plan

1. L'exemple : compter, additionner, comparer des dates (à vous : un cas vécu).
2. Le LLM comme générateur d'un appel d'outil plutôt que d'une réponse.
3. Vérifier le résultat par du code.
4. Les limites : quand le calcul n'est pas formalisable.

## Matière

- **À vous :** un cas vécu.
- **À recouper :** les études sur les limites arithmétiques des LLM. Ne citer aucun chiffre sans source primaire.
